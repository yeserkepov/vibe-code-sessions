Проекты

Выбери свой проект.

8 вариантов с мини-гайдами. Каждый — пошаговые промпты от нуля до готового результата.

Личная страница-визитка
⭐
HTML файл с твоим именем, фото, ссылками. Открывается в браузере, можно выложить онлайн.
HTML + CSS
1
Базовая структура
Создай одностраничный HTML файл — личная визитка. Моё имя: [ИМЯ], должность: [ТЕКСТ], email: [EMAIL]. Стиль: тёмный фон, белый текст, минималистично, по центру. Без внешних библиотек — только HTML и CSS в одном файле.
2
Фото / аватар
Добавь круглый аватар в верх страницы. Пока используй placeholder с via.placeholder.com размером 150x150.
3
Ссылки на соцсети
Добавь кнопки-иконки для Telegram, Instagram и LinkedIn. Используй emoji как иконки (✈️ 📸 💼). Ссылки пока пустые (#). Кнопки в ряд, с отступами.
4
Анимация
Добавь плавное появление контента при загрузке (fade in через CSS). Hover эффект на кнопки — лёгкое увеличение при наведении.
5
Мобильная версия
Сделай страницу адаптивной для мобильного. Проверь что на ширине 375px всё читается и не вылезает за края.
Деплой: перетащи файл на netlify.com/drop — получишь ссылку за 10 секунд.
Генератор рецептов
⭐
Вводишь ингредиенты — получаешь рецепт. Фильтры по диете, избранное, красивый вывод.
Python CLI
1
Базовый генератор
Создай Python скрипт recipe_generator.py. Спрашивает: "Какие ингредиенты у тебя есть? (через запятую)" Выбирает случайный рецепт из встроенного списка где есть хотя бы 2 введённых ингредиента. Добавь 10 рецептов прямо в код.
2
Красивый вывод
Рецепт выводить красиво: - Название большими буквами - Ингредиенты с галочками ✓ - Шаги пронумерованно - Время приготовления
3
Фильтр по диете
Добавь вопрос "Есть ли ограничения?" с вариантами: 1 — без ограничений, 2 — вегетарианское, 3 — без глютена. Пометь каждый рецепт тегами в коде.
4
Избранное
После показа рецепта спроси "Добавить в избранное? (y/n)" Если да — сохрани в файл favorites.txt. Если ввести "избранное" при старте — показать сохранённые.
5
Главное меню
Сделай меню при запуске: 1. Найти рецепт по ингредиентам 2. Случайный рецепт 3. Мои избранные 4. Выход Цикл — меню показывается снова после каждого действия.
Таблица расходов
⭐
Записываешь расходы, видишь статистику по категориям, экспортируешь отчёт.
Python + CSV
1
Запись расхода
Создай Python скрипт budget.py. Спрашивает: сумму, категорию (еда/транспорт/развлечения/другое), описание. Сохраняет в expenses.csv с датой и временем.
2
Просмотр расходов
Добавь просмотр всех расходов. Таблица: дата | категория | сумма | описание. В конце — итого за всё время.
3
Фильтры
Добавь фильтрацию: - По категории - За текущий месяц - За последние N дней (пользователь вводит число)
4
Статистика
Добавь команду "статистика": - Топ-3 категории по расходам - Средний расход в день за 30 дней - Самая дорогая покупка
5
Отчёт
Генерация report.txt: - Итоги за текущий месяц по категориям - Сравнение с прошлым месяцем (больше/меньше на сколько %)
Мини Landing Page
⭐
Красивая страница для твоей идеи или продукта. Анимации, мобильная версия, форма подписки.
HTML + CSS + JS
1
Структура
Создай одностраничный HTML landing page для [ИДЕЯ]. Структура: шапка с навигацией, hero секция с CTA, секция "Преимущества" (3 карточки с emoji), футер. Стиль: современный, [ЦВЕТ] акцент, белый фон. Только HTML+CSS, один файл.
2
Hero секция
Hero сделай впечатляющим: - Градиентный фон - Анимированный заголовок (появляется слайдом снизу) - Кнопка CTA с hover эффектом и тенью - Подпись: "Уже X человек попробовали"
3
How it works
Добавь секцию "Как это работает" — 3 шага пронумерованно: иконка-номер, заголовок, описание. Горизонтальная линия соединяет шаги на desktop.
4
Форма подписки
Секция "Получить ранний доступ": поле email, кнопка. При клике показать alert "Спасибо! Мы свяжемся с вами". Только frontend, без сервера.
5
Мобильная версия
Добавь hamburger меню для мобильного. Карточки и шаги — в столбик на экранах меньше 768px. Протестируй при ширине 375px.
Деплой: netlify.com/drop — перетащи файл, получи ссылку.
Переименование файлов
⭐⭐
Скрипт берёт папку и переименовывает файлы по правилу. Предпросмотр, подтверждение, лог.
Python
1
Список файлов
Создай Python скрипт rename_files.py. Спрашивает путь к папке. Выводит список всех файлов в ней.
2
Нумерация
Добавь нумерацию в начало каждого файла. Пример: "фото.jpg" → "001_фото.jpg" Сортировать по алфавиту перед нумерацией.
3
Предпросмотр
Перед переименованием покажи список: что было → что станет. Спроси подтверждение (y/n) прежде чем применять.
4
Фильтр по типу
Пользователь вводит расширение (например .jpg или .pdf). Скрипт переименовывает только файлы с этим расширением.
5
Лог
После переименования сохрани лог в rename_log.txt: дата, папка, список изменений (старое имя → новое имя).
Телеграм-бот
⭐⭐
Бот отвечает на команды, выдаёт случайные факты, запоминает имя пользователя.
Python + Telegram API
Сначала: напиши @BotFather в Telegram → /newbot → получи токен.
1
Эхо-бот
Создай Python телеграм-бот (python-telegram-bot v20+). Токен: [ТОКЕН ОТ BOTFATHER] Получает текст → отвечает тем же текстом. Команда /start с приветствием.
2
Установка и запуск
Напиши команду для установки нужных библиотек и как запустить бота.
3
Случайные факты
Добавь команду /fact — бот отвечает случайным интересным фактом. Список из 15 фактов прямо в коде (не нужен внешний API).
4
/help
Добавь /help — показывает список всех команд с описанием.
5
Запоминание имени
Команда /setname — пользователь вводит имя, бот запоминает и обращается по имени в следующих сообщениях. Хранить в словаре в памяти (база данных не нужна).
Квиз в терминале
⭐⭐
Викторина на любую тему. Таймер, подсказки, таблица рекордов, уровни сложности.
Python CLI
1
Базовый квиз
Создай Python скрипт quiz.py — викторина в терминале. Тема: [ИСТОРИЯ / ГЕОГРАФИЯ / КИНО / НАУКА] 10 вопросов, 4 варианта (a/b/c/d). В конце: счёт X из 10.
2
Таймер
Таймер 15 секунд на каждый вопрос. Если время вышло — вопрос засчитывается как неправильный.
3
Подсказки
У каждого вопроса одна подсказка. Игрок запрашивает подсказку (введя "?") но теряет половину очка за вопрос.
4
Таблица рекордов
После квиза спроси имя игрока. Сохрани результат в leaderboard.txt. При старте показывать топ-5 лучших результатов.
5
Уровни сложности
При старте выбор: 1 — лёгкий (5 вопросов, без таймера) 2 — средний (10 вопросов, 20 сек) 3 — сложный (15 вопросов, 10 сек)
Скачивание картинок
⭐⭐
Читает список URL, скачивает файлы, фильтрует по типу, создаёт отчёт.
Python + requests
1
Базовый скачиватель
Создай Python скрипт downloader.py. Читает urls.txt (каждая строка — один URL). Скачивает каждую картинку в папку downloads/. Показывает прогресс: "Скачиваю 1 из 10: [url]"
2
Умные имена файлов
При сохранении: брать имя из URL. Если имя уже существует — добавить номер: photo.jpg → photo_1.jpg Если имя нечитаемое — image_001.jpg, image_002.jpg и т.д.
3
Фильтр по типу
Пользователь вводит типы файлов через запятую (jpg,png,gif). Скачивать только файлы указанных типов, остальные пропускать.
4
Отчёт
После скачивания показать итог: - Успешно: N файлов - Ошибок: N файлов Сохранить отчёт в download_log.txt.
5
Ограничение скорости
Пауза 1 секунда между скачиваниями (не перегружать сервер). Пользователь может указать задержку (по умолчанию 1). Показывать оставшееся время.
